# Peptide Explorer

An educational peptide research explorer designed to help people evaluate scientific evidence, understand study limitations, and interpret laboratory data.

This repository contains a static prototype of the educational experience. The core model is:

`Peptide → Claim → Study → Evidence Assessment → Limitations → Citation`

The prototype is intentionally static while the evidence model and educational approach are being developed.

## GitHub Pages

In repository **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Important boundary

This is an educational research tool, not medical advice. Regulatory status, scientific evidence, compounding status, and laboratory documentation are separate concepts and should not be used as proxies for one another.
